# 🚀 AURA: Agentic Unified Resource Assistant

## 🧠 Overview

AURA (Agentic Unified Resource Assistant) is a collaborative multi-agent AI system designed to guide students in academics, skill development, productivity, and career decision-making.

It addresses real-world student challenges such as:

* Confusion in choosing skills and career paths
* Poor time management and lack of consistency
* Last-minute exam preparation
* Lack of awareness of modern AI tools

AURA acts as an intelligent mentor that continuously guides, adapts, and supports students based on their behavior and goals.

---

## 🎯 Key Features

### 🤖 Multi-Agent System

AURA uses multiple specialized agents working together:

* **Decision Agent** → Decides what student should focus on
* **Planning Agent** → Creates structured daily/weekly plans
* **Monitoring Agent** → Tracks progress and consistency
* **Adaptation Agent** → Dynamically adjusts plans
* **Exam Survival Agent** → Helps in last-minute preparation
* **AI Tool Intelligence Agent** → Recommends relevant AI tools

---

### ⚡ Exam Survival Mode (USP)

* Analyze PDFs (notes, question papers)
* Identify important and repeated topics
* Provide high-impact study strategy for short time

---

### 🧠 Skill Intelligence

* Guides students on what to learn and when
* Prevents confusion and random learning
* Suggests structured career path

---

### 🌐 AI Tool Awareness

* Recommends modern AI tools
* Helps students stay updated with industry trends
* Improves productivity using automation tools

## 📊 How It Works

1. User enters:

   * Academic year
   * Career goal
   * Time available

2. System processes input

3. Multi-agent system:

   * Makes decisions
   * Creates plan
   * Tracks and adapts

4. If PDF uploaded:

   * Extracts text
   * Identifies important topics

5. Final output is shown in structured format
